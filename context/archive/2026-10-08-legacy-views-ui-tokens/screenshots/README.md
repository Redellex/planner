## Before → after

- **Surface.** Before: `bg-cosmic` hex gradient, a translucent glass card (`bg-white/10 backdrop-blur-xl`) and a blue→purple gradient `h1` on every one of these pages. After: the shadcn neutral dark tokens; the dashboard and `/manager/months` use the `/availability` shell (`bg-background`, `max-w-2xl`, `bg-card` panel with a token border), the auth pages and 403 one centred `max-w-sm` `bg-card` panel.
- **Controls.** Hand-built inputs with a purple focus ring and a purple-overridden submit are `Input` and the default `Button`; the dashboard links and "Go home" are `buttonVariants({ variant: "outline" })`; Lock/Unlock are `Button size="sm"` (secondary / outline). Text links follow the token "text link" row.
- **Feedback.** Raw `?error=` text and Supabase/PostgREST messages are gone: the auth pages show only their form's allow-listed messages (crafted text → "Could not sign in. Try again." / "Could not create your account. Try again."), in a destructive `Alert`. On `/manager/months` the result of a lock write is an `Alert` inside the row of its month (`&month=`), with a top fallback when the month is missing or invalid; crafted text → "Could not update the month. Try again.".
- **Field errors.** Colour-only red text is `Input aria-invalid` (destructive border and ring) plus an error line with `CircleAlert` tied by `aria-describedby`; a failed submit moves focus to the first invalid field.
- **Load failure.** Before, a failed lock read still listed every month as "Open" with a Lock button. After, only "Could not load the month locks. Reload the page." renders: no list, no buttons.
- **Focus.** Inputs, the password toggle, link buttons and Lock/Unlock show the token ring (`ring-ring/50`, 3px); before, a purple ring on inputs and the browser default elsewhere.
- **Pending.** Sign-in and sign-up disable the button with a spinner and "Signing in…" / "Creating account…" during the POST (before, the `useFormStatus` branch never rendered); Lock/Unlock is disabled with `aria-busy="true"` until the redirect. Back re-enables both.
- **Copy.** The dashboard drops the starter line and shows a Manager/Employee pill; confirm-email always says "Check your email" with a `MailCheck` icon; 403 says "Some pages are available to managers only. Ask a manager if you need access." and links "Go home"; the not-configured banner is an English `Alert` ("Warning: Supabase is not configured — …").
